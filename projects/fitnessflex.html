PROJECT OVERVIEW

A Flutter application built as a university capstone. The repository contains the app architecture, Firebase integration, navigation, workout interfaces and supporting fitness-related packages.

01 / THE CHALLENGE

Understand the problem.

Fitness apps need to bring together several different experiences without making users navigate disconnected screens. This capstone explores an app structure for fitness activities and related tools.

02 / THE APPROACH

Design the approach.

The codebase uses Flutter for the interface, a central application router for navigation, and Firebase initialisation with optional anonymous sign-in. Dependency configuration also includes Firestore, image picking, charts, and camera/pose-detection libraries; a dependency being present does not on its own establish production feature completion.

03 / HOW IT WORKS

Behind the build.

01

Application boot

Initialises Firebase before launching the Flutter application.

02

Navigation

Feature scaffolding
