PROJECT OVERVIEW

Study Buddy is a collaborative student productivity website containing to-do lists, study scheduling, focus timers, quotes and countdowns. The team report specifically identifies my Pomodoro timer and shared header/footer contributions.

01 / THE CHALLENGE

Understand the problem.

Study planning tools need to support both organisation and focused work without making the experience confusing. The group built a modular site with distinct pages for different study activities.

02 / THE APPROACH

Design the approach.

The Pomodoro JavaScript implementation manages configurable session and break lengths, timer state, DOM updates and an SVG progress ring. It handles starting, pausing, resetting and switching between work and break sessions.

03 / HOW IT WORKS

Behind the build.

01

Timer state

Keep session length, break length and remaining seconds in JavaScript.

02

Visual feedback

Update the numeric countdown and SVG progress circle each tick.

03

Session controls

Support pause, reset, starting a break and switching to the next focus session.

04 / MY ROLE

My contribution.

My documented work: implemented the Pomodoro timer and improved the shared header and footer. Other pages—such as the to-do list, weekly timetable and quotes—were built by fellow team members.
