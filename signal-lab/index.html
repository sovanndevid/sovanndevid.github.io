How the test works

1. Compute indicators only from the current and earlier finished candles. 2. Enter a single position on the next bar's open. 3. Use ATR stop/target; include a user-adjustable round-trip cost. 4. Exit at the first stop, target, or time limit. 5. Choose a parameter combination using only the first 70% of price history, then evaluate it on the last 30% without re-optimizing. 6. Treat a small sample or stale data as inconclusive.

No simultaneous positions. Gaps can fill worse than stop level. This simplified research engine is not a substitute for broker tick-level validation, exchange session calendars or walk-forward testing.
