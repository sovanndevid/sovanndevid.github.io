TEMPORAL NEURAL NETWORKS / SYNTHETIC INTEGRATION TESTS

Trained CNN and LSTM

NOT HUMAN VALIDATED

Both models were trained end-to-end on generated 45-frame motion sequences, using six virtual identities for training and two held-out virtual identities for testing. These are real model fits, but testing synthetic rules is not evidence of exercise-coaching quality.

Human dataset research remains separate: the older UI-PRMD accuracy numbers use author-pretrained latent embeddings and have upstream leakage. No claim that these neural networks outperform the human-data baselines, or that they can run on webcam pose sequences, is made.

The browser prototype mirrors FitnessFlex's existing squat state machine and feature extraction. The final implementation should define shared, tested data schemas so mobile and web use comparable feature and score versions.

SECURITY BY DESIGN

Zero service credentials

No OpenAI key, no Firebase config, and no backend credentials ship with this prototype. Rotate the previously exposed key and scrub its presence in Git history before using any connected service.
